# Чеклист запуска клиента

## Подготовка KB

- [ ] `company.yaml` заполнен: name, city, phone, hours.
- [ ] `website_url` и `telegram_url` заполнены.
- [ ] `allowed_domains` содержит продовый домен, не только `localhost`.
- [ ] `services.json`: минимум 5 услуг с синонимами.
- [ ] `prices.json`: цены на все услуги из `services.json`.
- [ ] `faq.md`: минимум 3 записи: адрес, запись, режим работы.
- [ ] `widget config`: цвета и заголовок под клиента.

## Проверка перед запуском

- [ ] `python backend/scripts/onboard_client.py {id} --dry-run` → нет блокеров.
- [ ] `python backend/scripts/client_launch_check.py --company={id}` → всё зелёное.
- [ ] `python backend/scripts/smoke_ai_scenarios.py --company={id}` → 22+/28.

## Технический запуск

- [ ] Домен добавлен в `ALLOWED_ORIGINS` в `.env`.
- [ ] Backend перезапущен после изменений.
- [ ] `bootstrap` возвращает 200 с продового домена.
- [ ] Виджет вставлен на сайт клиента и появляется через 5 сек.

## Финальная проверка руками за 5 минут

- [ ] `"покажи услуги"` → услуги этого клиента, не чужие.
- [ ] Цена на реальную услугу → ответ с оговоркой.
- [ ] Несуществующая услуга → бот не выдумывает.
- [ ] `"позовите оператора"` → статус `WAITING_OPERATOR`.
- [ ] Оператор берёт чат → `HUMAN_ACTIVE` работает.
- [ ] Оставить имя + телефон → лид в `leads.jsonl` с `company_id`.
- [ ] Telegram-уведомление пришло, если Telegram настроен.

## После запуска

- [ ] Первые 24 часа: проверить `logs/` на ошибки.
- [ ] Первая неделя: проверить unanswered questions.
- [ ] Обновить KB, если бот часто говорит `не вижу в базе`.
